# Problem

Provenance: ai-suggested research formulation, followed by ai-executed tests.

After tool semantics change, which observations are necessary to select
actions that complete a task and preserve protected state? The candidate
world support is public and finite; the actual world remains private.
Actions can irreversibly destroy future feasibility.

The user's confirmed choice is to implement P2. Details of the finite
benchmark and learning protocols were engineering/research choices made
during execution, not separate user endorsements of a scientific claim.

The delivered scope has three synthetic SQLite domains sharing two
operator families, set supervision, exact/static/learned controls, a separate
coupled-query extension, and one real small-model LoRA pilot.
Unknown-support discovery, external database parity, CUDA runs, and
structure-held-out learning remain untested.
